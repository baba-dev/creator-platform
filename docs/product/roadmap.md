# Product roadmap

## Foundation

- Monorepo, CI, local services, database schema, worker, provider contracts, and
  staging deployment assets.

## Private alpha

- Authentication, organizations, roles, manual OMR payments, immutable wallet,
  model catalogue, quoting, and BytePlus image generation.

## Internal beta

- Video generation, asset library, projects, admin operations, reconciliation,
  spend caps, and NVIDIA Creative Copilot.

## Client-network beta

- Voice generation after account entitlement is confirmed, brand kits, localized
  workflows, usage statements, MFA, backup restoration test, and
  production-readiness review.
